# Security

## Supported versions

Only what's live is supported: the game at https://jonathan-orlowski.dev/carmen, its records server, and the latest release.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through [GitHub's security advisories](https://github.com/jonorl/carmen/security/advisories/new), or email hello@jonathan-orlowski.dev.

Say what's affected, how to reproduce it, and what an attacker could do with it. You'll get a reply within a week.

Out of scope: anyone being able to record arrests under any name. There are no accounts by design: a name is a detective.
